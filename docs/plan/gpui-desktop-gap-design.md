# 图可视化库缺口设计

> 版本：v3.0 · 日期：2026-10-01
> 说明：旧版桌面化缺口设计未实施且与当前定位不符，已废弃。本文为重写版，不保留旧版内容。
> 当前定位：本项目是图可视化库，顺带提供 gpui；其他功能由消费方在 gpui 之上自建。

---

## 1. 库边界

在库内：图模型、布局、渲染、视图交互、导入导出。

不在库内：通用 UI 组件、主题、文本与代码编辑、后端客户端、领域面板、业务校验、多窗口。演示二进制仅作参考装配。

## 2. gpui 顺带提供

上游只读挂载，保持原始布局，禁止修改；本工作区经 path 依赖消费。升级 submodule 指针后重查 gpui API 签名。消费方自行引用同基线版本，本库不封装 gpui。

## 3. 现有缺口

- 图编辑原语：手势产出编辑动作，由消费方应用到图存储；本库不直接改图，不感知校验与 undo。
- 样式过渡原语：可插值属性的过渡机制，挂靠 gpui 重绘调度；本库不定义业务配色，不自建帧循环。
- 外部 id 映射：后端稳定 id 与库内索引的双向映射 helper，避免消费方各自手写。

## 4. 不做事项

组件库、编辑器、高亮、表格、后端桥接约定、按项目落地路线，本库一概不规划、不验收。
