# 图可视化库能力与适配分析

> 版本：v3.0 · 日期：2026-10-01
> 说明：旧版将本项目定位为桌面应用底座并规划组件库与后端桥接等内容，该方向未实施且与当前定位不符，已废弃。本文为重写版，不保留旧版内容。
> 当前定位：本项目是图可视化库，顺带提供 gpui；其他功能由消费方在 gpui 之上自建。

---

## 1. 定位

本项目交付两样东西：图可视化库（cg-*）与可复用的 gpui 快照。除此之外的桌面功能一律不在本项目内。

## 2. 本项目提供

- 图模型与算法：图存储、属性、变更事件、petgraph 算法桥。
- 布局：多布局引擎、变更驱动、增量与后台回写。
- 渲染与交互：画布、相机、拾取、样式、标签、选中覆盖、大图策略、导入导出。
- 演示二进制：仅用于验证库接线，不可依赖。

## 3. gpui 提供

只读 submodule 挂载上游快照，本工作区经 path 依赖消费。消费方自行引用同基线版本，本库不封装 gpui，不提供 UI 框架层。

## 4. 消费方自建

通用 UI 组件、文本与代码编辑、主题、后端客户端、领域面板、业务校验、回放与会话、多窗口。以上与图无内聚，由各项目在 gpui 之上自建。

## 5. 三项目图场景对照

linkrs、code-context-engine、wf-agent 的图展示、布局、框选、着色需求均落在本库范围内；各自的 Schema 面板、编辑器、详情页、执行态业务均由其自建，本库不感知。

---

## 6. 结论

图场景复用本库，非图功能各自在 gpui 上搭建。库只保证图侧的事件与渲染能力，不规定消费方的应用结构与后端形态。
